-- Top customer per region using QUALIFY (no CTE)
SELECT
  region,
  customer_id,
  SUM(revenue) AS total_rev,
  RANK() OVER (
    PARTITION BY region
    ORDER BY SUM(revenue) DESC
  ) AS rnk
FROM orders
GROUP BY 1, 2
QUALIFY rnk <= 3;

QUALIFY: Top-N Per Group

Without QUALIFY this requires wrapping in a CTE or subquery. QUALIFY filters on the window function result in the same query — like HAVING for GROUP BY.

Any window function result is filterable with QUALIFY.

External Tables
Query Parquet, ORC, and CSV files in S3, Azure, or GCS directly with Snowflake SQL — no ingestion, no data copy required.
What are External Tables?
A metadata layer over files in object storage. Snowflake queries the files directly — no COPY INTO, no storage duplication.
Create External Table
Point at an external stage with LOCATION, define the schema (or use INFER_SCHEMA), and set file format options.
INFER_SCHEMA
Auto-detect column names and types from Parquet or ORC files. No manual DDL needed — let Snowflake read the schema.
Partition Columns
Define partition columns based on directory structure. Enables partition pruning — only reads files matching WHERE predicates.
AUTO REFRESH
Use cloud storage events to automatically update the external table metadata when new files land — no manual REFRESH needed.
External Tables vs Iceberg
External Tables: simpler, any format, read-only. Iceberg: richer metadata, ACID transactions, better performance. When to use which.

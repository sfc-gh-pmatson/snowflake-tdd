-- Find all stores within 5km and their distance from a point
SELECT
  store_id, store_name,
  ST_DISTANCE(
    location,
    TO_GEOGRAPHY('POINT(-122.42 37.77)')
  ) AS dist_meters
FROM stores
WHERE ST_DWITHIN(
  location,
  TO_GEOGRAPHY('POINT(-122.42 37.77)'),
  5000
)
ORDER BY dist_meters;

Proximity Search

ST_DWITHIN filters to locations within a radius (meters). ST_DISTANCE returns the exact geodesic distance.

Runs entirely in Snowflake. No PostGIS, no export. Results can be exported as GeoJSON for any mapping tool.

Data Engineering on Snowflake
Ingest from any source, transform declaratively, orchestrate without external tools — one engine, one platform, zero data movement.
COPY INTO
Bulk-load files from internal or external stages into Snowflake tables. Supports CSV, JSON, Parquet, Avro, ORC, and XML. Transform data on load, validate before committing, and track load history to prevent duplicates.
Bulk load Multi-format Load history
Snowpipe
Serverless, event-driven file ingestion from cloud storage. Create a pipe with AUTO_INGEST — files land in S3, Azure Blob, or GCS and are automatically loaded the moment they arrive.
AUTO_INGEST S3 · Azure · GCS Serverless
Openflow
Snowflake-native data integration built on Apache NiFi. 200+ pre-built connectors for databases, SaaS, files, and APIs — with full CDC support from Oracle, MySQL, SQL Server, and Postgres. No-code pipeline builder, runs on SPCS.
200+ connectors CDC No-code NiFi-based
Snowpipe Streaming
Sub-second, row-level ingestion via SDK — no staging files required. Push rows directly into Snowflake channels and query them within milliseconds of commit. Built for Kafka, CDC, and IoT workloads.
Sub-second Channels Kafka · CDC · IoT
Dynamic Tables
The declarative pipeline primitive — write a SELECT query, set a TARGET_LAG, and Snowflake handles scheduling, dependency tracking, and incremental refresh. Chain tables to build multi-step pipelines in pure SQL.
Declarative TARGET_LAG INCREMENTAL
Streams & Tasks
Streams capture row-level change data (inserts, updates, deletes) on any table. Tasks trigger SQL or Snowpark execution on a schedule or when a stream has data — chain tasks with AFTER to build DAGs without an external orchestrator.
CDC DAGs Event-driven Serverless
dbt in Snowflake
Run dbt projects as native Snowflake objects — no external orchestration or dbt Cloud subscription needed. Deploy with snow dbt, schedule with Tasks, and execute with a single SQL statement.
EXECUTE DBT PROJECT snow dbt deploy Task-scheduled
Snowpark
Write DataFrame transformation pipelines in Python, Java, or Scala — running on Snowflake compute with no data leaving the platform. Build UDFs, UDTFs, and stored procedures natively.
Python Java / Scala No data movement

-- Full Document AI pipeline in one query
SELECT
  relative_path,
  AI_CLASSIFY(parsed,
    ['invoice','contract','receipt']
  ) AS doc_type,
  AI_EXTRACT(parsed,
    'vendor_name', 'invoice_number',
    'total_amount', 'due_date'
  ) AS fields,
  AI_REDACT(parsed, 'pii') AS safe_text
FROM (
  SELECT
    relative_path,
    AI_PARSE_DOCUMENT(
      @docs_stage, relative_path,
      {'mode': 'LAYOUT'}
    ):content AS parsed
  FROM DIRECTORY(@docs_stage)
  WHERE AI_FILTER(relative_path,
    'is a PDF or image file')
);

Full Pipeline in SQL

One query parses every file in a stage, classifies it, extracts structured fields, and redacts PII. No external orchestration needed.

Wrap this in a Dynamic Table or Task to process new files automatically as they land.

The DIRECTORY() table function lists all files in the stage, enabling batch processing across hundreds of documents.

Snowpark Container
Services
Run containerized workloads — any language, any framework — directly inside Snowflake with full governance and access to your data.
Any Language, Any Framework
Package any runtime — Python, R, C++, Java, custom ML frameworks — into an OCI container and run it on Snowflake compute. No ETL, no data movement: your container runs where the data lives.
CPU & GPU Compute Pools
Right-size compute for every workload. CPU pools for general services and APIs; GPU pools (NVIDIA) for model training, fine-tuning, and high-throughput inference at scale.
Built-in Container Registry
An OCI-compliant image registry lives inside your Snowflake account. Push private images with standard Docker tooling — governed by Snowflake RBAC, no external registry required.
Native App Distribution
Package container-based applications as Snowflake Native Apps and publish them to the Marketplace — giving customers one-click deployment without ever exposing underlying code or data.

Data Classification
Automatically detect PII, PHI, and sensitive data using ML classifiers — no manual column review required.
Horizon Catalog · Classification
🤖
Auto-Classification
Snowflake ML classifiers analyze column names, data types, and sample values to detect PII (emails, SSNs, phone numbers), PHI (medical record numbers), and financial data. System tags are applied automatically.
🌟
Custom Classifiers
Create domain-specific classifiers using CREATE PRIVACY CATEGORY and CREATE SEMANTIC CATEGORY to detect business-specific sensitive data patterns.
⚙
On-Demand & Scheduled
Run SYSTEM$CLASSIFY on any table or schema on-demand. Schedule classification to run automatically as new tables and columns are added.
-- Classify a single table on demand
CALL SYSTEM$CLASSIFY(
  'MY_DB.SCHEMA.CUSTOMERS',
  {'auto_tag': true}
);

-- Create a custom privacy category
CREATE PRIVACY CATEGORY internal_id
  COMMENT = 'Internal employee IDs';

-- View classification results
SELECT * FROM
  SNOWFLAKE.ACCOUNT_USAGE.DATA_CLASSIFICATION_LATEST
WHERE table_name = 'CUSTOMERS';

Install & Authenticate
One-line install via pip. Supports key-pair, OAuth, browser-based SSO, and federated auth. Profiles for multiple accounts and roles.
Manage Snowflake Objects
List, describe, execute SQL, manage warehouses, SPCS services, native apps, notebooks, stages — everything without opening Snowsight.
Git Integration
Connect a GitHub, GitLab, or Bitbucket repo directly to Snowflake. Branches, tags, and files become a Snowflake stage — execute code without copying it.
Deploy & Automate
Deploy Snowpark functions, stored procs, SPCS services, and native apps directly from the CLI. Plug into any CI/CD pipeline with environment-variable-based auth.

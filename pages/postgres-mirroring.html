Snowflake Postgres
Data Mirroring
Always-on, automatic replication from Postgres to Snowflake. Set it up once — tables stay in sync, schema changes included, forever.
Push-Based CDC — Not Pull
A snowflake_cdc Postgres extension continuously pushes change batches into Iceberg change logs on object storage. No external connector to manage, no snapshots that can conflict with changes.
Simple Setup with CREATE MIRROR
One SQL command replicates an entire Postgres database — or specific schemas. Schema changes (ADD COLUMN, DROP TABLE) replicate automatically with no manual intervention.
Live Views — Sub-Minute Lag
Live views merge unapplied change batches with the base table on-the-fly. Queries see data within seconds of commit — even if batches haven't been applied yet. Filter and aggregation pushdown keeps live view queries fast.
Transactional Consistency
Snowflake applies all tables forward in one transaction — exactly to a Postgres transaction boundary. Foreign keys and join correctness are preserved. Insert-heavy workloads are fast because inserts are appended, never upserted.

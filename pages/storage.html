Snowflake Storage
One storage layer for all data types — structured tables, semi-structured JSON, and unstructured files — with automatic micro-partitioning, clustering, and Time Travel built in.
Unstructured Data
Store documents, images, video, audio, and binary files natively alongside structured data. Query file metadata as a table, generate presigned URLs, and run AI extraction — without moving data to a separate system.
FILES DIRECTORY TABLE AI_PARSE_DOCUMENT Presigned URLs
Semi-Structured
Native VARIANT type stores JSON, Avro, Parquet, ORC, and XML without a fixed schema. Query nested fields with dot notation, flatten arrays into rows, and auto-detect column structure — all in standard SQL.
VARIANT FLATTEN INFER_SCHEMA dot notation
Structured Data
Full ANSI SQL typed columns with constraints, views, and Time Travel. Every table is automatically micro-partitioned and columnar — no tuning required. Secure views, materialized views, and transactional DML included.
Typed columns Constraints Time Travel Secure views
Micro-Partitioning
All Snowflake tables are automatically divided into immutable, compressed micro-partitions of 50–500 MB. Snowflake stores rich column-level metadata (min/max, distinct count, bloom filter) for each partition, enabling aggressive pruning without manual maintenance.
Immutable Columnar Partition pruning Zero maintenance

Define cluster keys to co-locate frequently filtered columns in the same micro-partitions. Automatic Reclustering keeps large tables tidy as data ages. Search Optimization Service accelerates equality and range lookups without changing queries.

Internal Stages
Snowflake-managed temporary and permanent file storage for data loading, transformation outputs, and pipeline intermediates. Three types: user stage (personal), table stage (bound to a table), and named stage (reusable, governed).
@~ user @%table Named stage PUT / GET
External Stages
Reference data in S3, Azure Blob, or GCS without loading it into Snowflake. Use a Storage Integration to decouple credentials from stage definitions. Query files in-place with external tables or load on-demand with COPY INTO.

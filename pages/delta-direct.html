Databricks Interop
Delta Direct
Query Databricks Delta tables natively in Snowflake. No conversion, no ETL, no data copy — reads the Delta transaction log directly.
How Delta Direct Works
Snowflake reads the Delta transaction log and Parquet files directly from your object storage — no data movement required.
Setup & Catalog Integration
Create an EXTERNAL VOLUME for storage access and a CATALOG INTEGRATION pointing at Unity Catalog, Glue, or a custom Delta catalog.
Querying Delta Tables
After setup, Delta tables appear as native Snowflake tables. Query with full SQL — joins, aggregations, window functions, Cortex AI.
Schema Evolution
Delta schema changes propagate automatically to Snowflake. Add a column in Databricks; Snowflake sees it on the next query.
Time Travel on Delta
Query historical snapshots of Delta tables using Snowflake AT/BEFORE syntax against Delta's transaction log versions.
Governance & Performance
Snowflake RBAC, masking, and row access policies apply to Delta tables. Predicate pushdown and partition pruning deliver native performance.

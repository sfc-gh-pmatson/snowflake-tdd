-- Query nested JSON + flatten arrays + build response
SELECT
  e:user:id::STRING AS user_id,
  e:event_type::STRING AS event_type,
  tag.value::STRING AS tag
FROM events e,
  LATERAL FLATTEN(
    input => e:tags
  ) tag
WHERE e:user:tier::STRING = 'premium';

JSON + FLATTEN in one query

Access nested JSON fields with colon path syntax. LATERAL FLATTEN explodes the tags array so each tag becomes its own row joined to its parent event.

The WHERE clause filters on a nested field — Snowflake pushes the predicate down into the VARIANT scan.

External Engines
Spark, Flink, Kafka, Trino, Dremio, Databricks — native connectors and open standards let any engine read from and write to Snowflake.
Apache Spark™
Snowpark for Spark: run PySpark on Snowflake compute. Or connect an external cluster via Spark Connector.
Trino
Federated SQL across Snowflake + S3/Hive in one query. Snowflake as a Trino catalog via JDBC.
Apache Flink
Stream Flink output into Snowflake via Kafka Connector or Snowpipe Streaming for sub-second latency.
Databricks
Iceberg and Delta Sharing let both platforms share live data bidirectionally — no copies, no ETL.
AWS Glue
Glue Data Catalog as Iceberg source for Snowflake. Glue ETL jobs read/write Snowflake via Spark Connector.
Microsoft Fabric
OneLake Iceberg and Delta Sharing enable Snowflake ↔ Fabric bidirectional access over shared storage.
dbt
SQL transformation framework with first-class Snowflake support — incremental models, merge strategies, dynamic tables.
Apache Airflow
Orchestrate Snowflake workflows via the Snowflake provider — SQL operators, sensors, and task dependency graphs.

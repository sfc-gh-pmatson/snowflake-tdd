Isolation Model
Compute is fully decoupled from storage. Multiple warehouses can query the same data simultaneously with zero resource contention — BI, ETL, and AI workloads never fight over resources.
▶
Auto-Suspend & Resume
Warehouses suspend after idle timeout (min 1 min) and resume in ~2 seconds. Credits consumed only while running — zero idle cost. The foundation of Snowflake’s pay-per-use model.

Caching Tiers
Result Cache
24 hrs
Identical queries returned instantly with zero credits. Shared across all users. Automatic — no configuration required.
Data Cache
Local SSD
Frequently accessed micro-partitions cached on warehouse nodes. Reduces remote storage I/O. Stays warm while warehouse is running.
Metadata Cache
0 Credits
Row counts, MIN/MAX values, NULL counts answered from metadata — no data scan required. Enables aggressive partition pruning.

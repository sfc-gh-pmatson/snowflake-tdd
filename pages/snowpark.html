-- Snowpark Python: DataFrame + UDF
from snowflake.snowpark import Session
from snowflake.snowpark.functions import udf, col

-- DataFrame: lazy, pushes SQL to Snowflake
df = session.table("orders")
result = df.filter(
    col("status") == "open"
).group_by("region")
 .agg(sum("amount"))

-- UDF: Python function callable from SQL
@udf(name="classify_risk",
     return_type=StringType())
def classify_risk(score: float) -> str:
    if score > 0.8: return "high"
    if score > 0.5: return "medium"
    return "low"

Snowpark Execution Model

The DataFrame is lazy: no query runs until you call .collect() or .show(). Snowflake compiles the entire chain into a single optimized SQL query.

UDFs are uploaded to Snowflake and run server-side. No data is returned to the client during processing.

No data movement. Your Python logic executes inside Snowflake's compute layer alongside the data.

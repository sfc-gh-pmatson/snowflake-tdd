🏷
System & Custom Tags
Snowflake provides built-in system tags (e.g. SNOWFLAKE.CORE.SENSITIVITY) and lets you create custom tags with CREATE TAG for your own classification taxonomy.
⭣
Tag Propagation
Tags set on a table inherit to all columns by default. Column tags propagate to query results. Tags flow through views and joins — governance follows data, not just objects.
🔒
Policy Inheritance
Masking and row-access policies can be bound to a tag rather than a column. Tag a column “PII” and the masking policy applies automatically — to every column with that tag, everywhere.
-- Create a custom sensitivity tag
CREATE TAG governance.tags.pii
  ALLOWED_VALUES 'email', 'ssn', 'phone';

-- Apply tag to a column
ALTER TABLE customers
  MODIFY COLUMN email
  SET TAG governance.tags.pii = 'email';

-- Bind masking policy via tag (tag-based policy)
ALTER MASKING POLICY mask_pii
  SET TAG governance.tags.pii;

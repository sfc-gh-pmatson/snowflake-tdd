Generally Available
Snowflake Native Apps
Ship code directly into consumer accounts. Your logic runs next to their data — no data movement, full governance.
App Package
Provider-side container that bundles versions, code, and distribution logic for your application.
Setup Script
SQL script that runs at install time to create objects in the consumer's account — procedures, views, roles.
Application Roles
Fine-grained access control defined by the provider. Consumers grant app roles to their users — not raw Snowflake privileges.
Versioning & Patches
Release channels let you push updates incrementally. Consumers on auto-upgrade receive patches transparently.
Streamlit Frontend
Embed a Streamlit app inside your Native App — consumers get a full UI running in their account, no hosting required.
SPCS Container Apps
Include containerized microservices (APIs, ML inference) that run in consumer's Snowpark Container Services environment.

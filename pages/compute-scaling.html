Warehouse Scaling
Three levers to match compute to any workload.
Scale Across
Separate warehouses,
isolated workloads
Run different workloads on dedicated warehouses — independent sizing, cost tracking, and suspension per team.
■
No Resource Contention
BI queries never compete with ETL loads or ML training. Each warehouse is a fully isolated compute cluster against the same shared storage.
⚙
Independent Controls
Each warehouse has its own size, auto-suspend config, resource monitor, and RBAC. Suspend ETL overnight without touching BI.
$
Chargeback Ready
Attribute credits to teams by querying QUERY_HISTORY per warehouse. Pair with resource monitors for per-team budget guardrails.
-- Dedicated warehouse per workload
CREATE WAREHOUSE bi_wh
  WAREHOUSE_SIZE = 'MEDIUM'
  AUTO_SUSPEND = 300;

CREATE WAREHOUSE etl_wh
  WAREHOUSE_SIZE = 'XLARGE'
  AUTO_SUSPEND = 60;

Same Cost. 8× Faster.
Doubling the servers halves the runtime — and you pay per server, per second. Go from XS to L (8× servers) and your query runs 8× faster at the exact same credit cost.
▲
Scale Up & Down Instantly
Resize a running warehouse with a single SQL statement — no downtime, no migration. Scale up for a heavy batch job, scale back down immediately after.
-- Resize takes effect on next query
ALTER WAREHOUSE my_wh SET
  WAREHOUSE_SIZE = 'LARGE';

-- Scale back down when done
ALTER WAREHOUSE my_wh SET
  WAREHOUSE_SIZE = 'SMALL';
Scale Out
More clusters,
no queue
Add capacity for concurrency — through multi-cluster warehouses or adaptive throughput scaling.
▶▶
Multi-Cluster Warehouses
When users queue, MCW spins up identical clusters automatically. Each cluster handles its own query queue. AUTO mode scales 1–10 clusters; suspends excess when idle.
☉
Adaptive Warehouses
Gen2 warehouses auto-tune throughput for mixed workloads using QUERY_THROUGHPUT_MULTIPLIER (1–3×) — without adding clusters or resizing.
See Specialized Compute →
$
Credits
Each active MCW cluster bills at the warehouse T-shirt rate. Adaptive scaling adds no extra credit cost — it’s built into Gen2.
-- Create a multi-cluster warehouse
CREATE OR REPLACE WAREHOUSE analytics_wh
  WAREHOUSE_SIZE = 'MEDIUM'
  MIN_CLUSTER_COUNT = 1
  MAX_CLUSTER_COUNT = 3
  AUTO_SUSPEND = 60
  SCALING_POLICY = 'ECONOMY';

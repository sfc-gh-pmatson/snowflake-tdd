CREATE FAILOVER GROUP MY_FAILOVER_GROUP

  -- What to replicate
  OBJECT_TYPES = ALL
  -- ( USERS, ROLES, WAREHOUSES, RESOURCE MONITORS,
  --   DATABASES, NETWORK POLICIES, INTEGRATIONS, SHARES )

  ALLOWED_DATABASES = ALL
  -- ( DB1, DB2, ...  )

  -- Where to replicate it
  ALLOWED_ACCOUNTS = ORG_NAME.TARGET_ACCOUNT_NAME

  -- When to replicate
  REPLICATION_SCHEDULE = '10 MIN'
;

What to replicate

OBJECT_TYPES = ALL replicates users, roles, warehouses, resource monitors, databases, network policies, integrations, and shares. You can scope this to specific object types if needed.

Where to replicate it

ALLOWED_ACCOUNTS specifies the target account or list of target accounts to which replication and failover of specified objects from the source account is enabled.

When to replicate

REPLICATION_SCHEDULE = '10 MIN' keeps the secondary in sync every 10 minutes, giving you a Recovery Point Objective (RPO) of <10 minutes with near-zero RTO on failover. Can also use CRON.

-- Full time-series pattern: scaffold + gap-fill + rolling average
WITH spine AS (
  SELECT d::DATE AS day
  FROM TABLE(DATE_SPINE('day',
    '2025-01-01'::DATE,
    CURRENT_DATE()))
)
SELECT
  s.day,
  COALESCE(COUNT(e.event_id), 0) AS events,
  AVG(COUNT(e.event_id)) OVER (
    ORDER BY s.day
    ROWS BETWEEN 6 PRECEDING AND CURRENT ROW
  ) AS rolling_7d_avg
FROM spine s
LEFT JOIN events e
  ON e.event_date = s.day
GROUP BY 1
ORDER BY 1;

Complete Time Series Pipeline

DATE_SPINE generates every day in the range. LEFT JOIN ensures dates with no events show 0, not NULL. The rolling average window runs over the complete scaffold.

No complex CTEs for gap-filling. One clean query.

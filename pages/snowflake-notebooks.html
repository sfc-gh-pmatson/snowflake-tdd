import pandas as pd

# Reference the previous SQL cell's result

# Call Cortex AI on a column
result = session.sql("""
  SELECT review_text,
    AI_SENTIMENT(review_text) AS sentiment
  FROM reviews LIMIT 1000
""").to_pandas()

result.hist(column='sentiment')

Python Cell Pattern

Use get_active_session() to get the Snowflake session. Reference previous SQL cell results with cell1.to_pandas().

Cortex AI functions are called via session.sql() — they run server-side on the full dataset before results come back to Python.

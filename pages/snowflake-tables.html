Time Travel & Fail-Safe
Query any table as it existed at a past timestamp, offset, or query ID — without restoring a backup. UNDROP TABLE recovers a dropped table within the retention window. Fail-Safe extends 7 days beyond Time Travel for Snowflake-assisted recovery.

Zero-Copy Clone
CREATE TABLE ... CLONE is a metadata-only operation — no data is copied at clone time. Clones share underlying micro-partitions with the source. New writes to either side diverge independently. Clone entire databases or schemas in milliseconds.
InstantNo data copyAT(TIMESTAMP)
MERGE — Upsert Patterns
MERGE INTO handles upserts, SCD Type 1 and Type 2 patterns, and conditional logic in a single atomic operation. Supports multiple WHEN MATCHED clauses with different conditions and WHEN NOT MATCHED BY SOURCE for delete-from-target.

Change Tracking
Enable CHANGE_TRACKING on any table to capture row-level inserts, updates, and deletes. Query changes directly with CHANGES(INFORMATION => DEFAULT) or consume them via Streams for downstream pipeline triggers.

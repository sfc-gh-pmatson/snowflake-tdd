## Key Messaging Notes

- **Core pitch:** Easy, Connected, Trusted — single platform for all workloads
- **AI angle:** Universal AI Catalog (Horizon) provides context + governance; Cortex AI for agents, analyst, search, code
- **Performance:** 3 dimensions of scaling (UP/OUT/ACROSS); same work same cost; 8x faster at same price
- **Openness:** Iceberg + Polaris + Openflow + MCP; no vendor lock-in; any engine, any storage
- **Interactive/OLTP:** Interactive Tables (PrPr) + Interactive Warehouses (always-on) for low-latency
- **Migration:** SnowConvert AI handles Teradata, Oracle, Redshift, Synapse, BigQuery, etc.
- **Cost:** ~50% Snowpipe savings; adaptive warehouses eliminate manual sizing; unified FinOps UI

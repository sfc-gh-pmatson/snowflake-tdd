## Key Messaging Notes

- **Core pitch:** Easy, Connected, Trusted — single platform for all workloads
- **AI angle:** Universal AI Catalog (Horizon) provides context + governance; Cortex AI for agents, analyst, search, code
- **Performance:** 3 dimensions of scaling (UP/OUT/ACROSS); same work same cost; doubling servers halves run time
- **Openness:** Iceberg v3 + Polaris + Openflow + MCP; no vendor lock-in; any engine, any storage, any format
- **Interactive/OLTP:** Interactive Tables (Private Preview) + Interactive Warehouses (always-on) for low-latency; Serverless Tasks for pipeline automation
- **Migration:** SnowConvert AI handles Teradata, Oracle, Redshift, Synapse, BigQuery, and more
- **Cost:** ~50% Snowpipe savings; adaptive warehouses eliminate manual sizing; unified FinOps UI with cost anomaly detection
- **Data Engineering:** Schema Detection/Evolution, Dynamic Tables, Streams, Triggered Tasks, Event Tables — full pipeline automation
- **Security depth:** 11 governance/policy slides covering tagging, classification, row/column/masking policies, tokenization, and object dependencies
- **Sharing depth:** 5 new collaboration slides covering listing types, auto-fulfillment, provider analytics, and marketplace overview
